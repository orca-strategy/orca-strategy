
❓ 虎鲸策略 V1 (Orca Strategy V1) 常见问题解答 (FAQ)


一、 资金安全与权限相关（用户最关心）

Q1：把 API 填进程序里，我的币安资金安全吗？作者或技术人员能转走我的币吗？
• 绝对无法转走。创建币安 API 时，严禁勾选“允许提现”权限（仅需勾选“允许合约交易”），即使极端情况下密钥泄露，任何人都无法将资金转出您的账户。
• 本地隔离运行：程序完全运行在您自己租用的独立云服务器上，API 密钥通过 set_api.sh 脚本加密保存至您本地的系统服务配置中（权限 600，仅 root 可读），不经过任何第三方服务器。
Q2：如果请你们提供“付费代安装”服务，你们会接触到我的 API 密钥吗？
• 零接触密钥。技术人员仅为您搭建好运行环境与后台守护进程；环境装好后，您先修改服务器 root 密码，再亲自运行 ./set_api.sh 输入您的 API Key 和 Secret（输入 Secret 时屏幕自动隐藏字符防窥），全程无需向任何人透露密钥。

二、 运行环境与部署报错相关

Q3：我应该购买什么配置、什么系统的云服务器？大概多少钱一个月？
• 配置要求：1 核 CPU、1GB 或 2GB 内存的海外节点 VPS（推荐 AWS 东京/新加坡、Vultr、DigitalOcean 等，连接币安 API 延迟最低），月租仅需 $5 – $20 美元（约 35 – 140 元人民币）。
• 操作系统（极其重要）：强烈推荐选择 Debian 12 / 13（64位） 或 Ubuntu 22.04 / 24.04。
• 避坑提醒：请勿选择 Debian 10 或 Debian 11，这两个旧版本官方软件源已归档下线，执行安装时会报 404 Not Found 或 curl: command not found 错误。
Q4：为什么我刚启动程序，日志里就报错 -4061: Order's position side does not match user's setting？
• 原因：因为虎鲸策略采用多空独立对冲的双向持仓逻辑，而您的币安合约账户默认处于“单向持仓模式”。
• 解决办法：登录币安 App 或网页端 -> 进入 U 本位合约 -> 点击右上角 偏好设置（设置图标） -> 仓位模式 -> 切换为 【双向持仓模式（Hedge Mode）】（注意：切换前需确保当前没有任何未平仓位和挂单）。
Q5：运行一键安装命令后，提示 ❌ 错误：API Key 或 Secret 不能为空 怎么办？
• 这是因为通过管道符（| bash）运行脚本时占用了终端的键盘输入通道，并非安装失败，此时环境其实已经全部装好了。
• 您只需手动输入一行命令即可正常进入填写界面：bash
cd /root/orca-strategy && ./set_api.sh
Use code with caution.

三、 策略运行与资金管理相关

Q6：这个机器人交易哪些币种？需要准备多少本金？
• 交易品种：主动核心交易对为 SOLUSDT，联动助理交易对为 HYPEUSDT、BNBUSDT、XRPUSDT，同时实时监控 BTCUSDT 与 SPYUSDT 作为全局信号源。
• 资金建议：程序默认使用 10 倍杠杆，单笔开仓占用可用余额的 2% – 4%。由于币安合约有最小下单金额限制（通常单笔名义价值需 ≥ 5–20 USDT），建议测试验证阶段准备 100 – 300 USDT，正式运行建议 500 USDT 以上，避免因单笔金额过小触发交易所最小下单量报错。
Q7：为什么我看到程序开了好几个单子后，好像停止继续加仓了？
• 这是内置的单边防爆仓硬上限保护。为了防止极端行情下无限加仓导致穿仓，程序限制单个币种的单个方向（多或空）累计占用保证金不能超过可用余额的 3%。达到上限后会自动停止该方向加仓，等待止盈或对冲信号触发。
Q8：触发“25% 回撤熔断停机”是怎么回事？触发后会自动平仓吗？
• 会立即全平并停机。当监测到账户可用余额（综合考虑已占用保证金与实时浮亏）较历史峰值回撤超过 25% 时，程序会立刻撤销所有挂单、对策略内所有持仓执行市价全平，随后彻底退出程序（守护进程不会再次自动拉起），最大限度保住剩余本金。
• 熔断后如何重新开启：熔断记录保存在本地 risk_state.json 文件中。如果您复盘确认后希望重新启动机器人，需先删除该状态文件再重启服务：bash
rm -f /root/orca-strategy/risk_state.json && systemctl restart crypto-bot
Use code with caution.
Q9：能不能自己修改杠杆倍数或单笔仓位比例？
• 可以。杠杆倍数可在 orca_strategy_v1.py 顶部的 TRADING_CONFIG 中将 'leverage': 10 修改为您期望的倍数（新手建议调低至 3–5 倍以降低风险）；具体子策略的仓位比例位于代码后半段的 execute_open_order 调用参数中，修改后执行 systemctl restart crypto-bot 即可生效。

四、 日常运维常用命令速查

登录服务器终端后，可直接复制以下指令管理您的机器人：
• 查看运行状态：systemctl status crypto-bot（显示绿色 active (running) 即为正常）
• 查看实时交易日志：journalctl -u crypto-bot -f（按 Ctrl + C 退出查看，不影响后台运行）
• 重启交易程序：systemctl restart crypto-bot
• 紧急停止程序：systemctl stop crypto-bot
• 重新修改 API 密钥：cd /root/orca-strategy && ./set_api.sh
