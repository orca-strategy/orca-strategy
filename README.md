## 特性概览

- **双向持仓**：多空独立管理，支持对冲
- **市价开仓 / 限价止盈**：开仓即时成交，止盈减仓 50% 挂限价
- **多重触发信号**
  - BTC 2 秒脉冲（涨跌幅 ≥ 0.18%）
  - SPY 1 分钟放量信号（涨跌幅 ≥ 0.06% + 3 倍量）
  - BTC 1m 分型 + 放量（3~8 倍 / >8 倍极值）
  - BTC 15m 强势突破 + 8 倍放量
  - BTC 趋势持续 ≥8h 的价格同向确认
  - 市场情绪（资金费率 + 成交量比率）
- **全局风控**
  - 峰值回撤 > 25% 熔断并全平
  - 多空合计盈利 > 亏损 ×1.3 时锁死全平
  - 仓位归零 18 分钟冷却
- **工程化**
  - 日志滚动 + 磁盘保护 + 定期截断
  - 守护模式异常自动重启（指数退避）
  - 启动自动清理遗留挂单
  - WebSocket + REST 双重数据源
