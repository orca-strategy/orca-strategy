# 虎鲸策略 V1 (Orca Strategy V1) — 开源币安量化交易机器人

**简体中文** | [English](README_EN.md)

基于 **币安 (Binance) USDT 本位永续合约** 的多交易对自动化量化交易程序，采用「主动交易 + 助理交易」双层协同架构，支持 7×24 小时无人值守运行。

> ⚠️ **高风险提示**：本策略涉及高杠杆与加密货币衍生品交易。代码开源仅供技术研究，**不构成投资建议，使用风险自负**。启动前请务必在币安 U 本位合约中开启双向持仓模式。

---

## ✨ 核心特性概览

* **双层协同交易架构**：主动核心主攻波段，搭配助理交易对实现超短线抢入与对冲。
* **跨市场信号驱动**：结合多周期共振与情绪过滤机制。
* **全局风控防线**：具备回撤熔断、盈亏比锁盈及强制冷却期机制。
* **生产级工程化**：支持 WebSocket + REST 双数据源、断线重连及日志自动滚动。
